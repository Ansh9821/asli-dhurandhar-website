# Asli Dhurandhar Website

This repository contains a premium, mobile-responsive restaurant landing page for **Street Food ka Asli Dhurandhar** in Sheikh Sarai, New Delhi.

## Included
- Luxury themed landing page
- Hero section with menu highlights and trust stats
- About section
- Highlighted menu cards
- Reviews/testimonials
- Visit/contact information section
- Call-to-action section
- Smooth reveal animations and subtle tilt effects

## Run locally
Open `index.html` in a browser, or serve the folder with a local static server.

Example:

```bash
python3 -m http.server 8000
```

Then visit: http://localhost:8000

- `index.html`
